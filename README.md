# BuilderSpace 社团吉祥物：完整项目协作入口

更新：2026-11-17（悉尼）。这是新版产品范围与协作约定，尚未实现的功能不代表已完成。

GitHub 项目仓库：[crystal574-star/builderspace-mascot](https://github.com/crystal574-star/builderspace-mascot)。仓库只包含本玩偶项目；集成目标的外部源码不随仓库上传。

## 产品目标

完整版是一只具有社团外形、屏幕表情、触摸反应和语音交流能力的实体吉祥物。平时在桌面无线连接 echo-agent 帮用户做事；活动时可携带展示、互动并介绍 BuilderSpace。

第一阶段仍然只做屏幕表情：采购一块带 PSRAM 的 ESP32-S3 开发板，加一块约 2 英寸 SPI 彩屏，完成脸、眨眼、视线和表情切换。触摸、无线、echo、语音和活动样机按阶段增加。现有 C3 保留用于灯带实验；P4 在同一 S3 上评审音频组合，避免计划性换板。初次烧录可用 USB；日常数据通信采用 Wi-Fi，先用 USB 电源供电。身体动作、集成电池、蓝牙和批量生产是后续选配，不是当前第一阶段前置条件。

## 电脑上的屏幕表情预览

P1 的电脑预览位于 [preview/](preview/README.md)，2026-11-19 起改用 EchoAgent 刘海 Bot 的表情：原版 11 张脸、5 种样式、4 种身形、8 套配色和动作，可在页面上切换对照；样式等尚待用户选定。从仓库根目录运行：

```sh
python3 -m http.server 8877 --bind 127.0.0.1 --directory preview
```

打开 http://127.0.0.1:8877 。这是纯本地演示，不连接 echo-agent；真实 S3 屏幕仍未验证。

## 当前硬件

用户确认持有 ESP32-C3 ×6、WS2812 灯带、面包板、杜邦线、WS2812B 2020 灯珠 ×80。尚无屏幕。C3 确切板型、排针状态和 GPIO 可用性需要实物核对。

屏幕候选为 Waveshare 2inch LCD Module（SKU 17344，240×320、SPI、ST7789 系列、非触摸），只购一块验证。最终接线以购买的 S3 板型和屏幕实物为准。不要提前把其他板子的引脚表写死。

## 开发协作方式

1. 采用四个工作包：A 总集成与固件、B 表情预览、C 电脑桥接、D 内容与角色。T0–T15 仅为子任务索引，每个模块一名交付负责人。
2. 每个执行者先读本文件、接口约定和对应任务，再在进度表中认领。
3. 每项任务使用独立分支或 worktree；多个 agent 不同时修改同一模块。Git 分支默认前缀 `codex/`。
4. 推荐目录是后续实现约定，并非已存在代码。首次创建共享工程、构建入口或共享头文件由总集成人负责。
5. 接口以 `docs/INTERFACES.md` 为准；需要变更时先提出差异，由总集成人统一更新，再同步受影响模块。
6. 交付包含代码、运行步骤和验收证据；总集成人完成合并和端到端验证，不能把各模块单独通过等同于整机完成。
7. 把代码和交接文件提交到同一仓库；不依赖某个聊天记忆才能继续工作。

## 完整版阶段顺序

P1 屏幕表情 → P2 触摸互动 → P3 无线与 echo 状态 → P4 语音与任务交互 → P5 活动接待与外形 → P6 稳定展示与成员交接。P7 身体动作、集成电池和独立运行按需开启。详见 PHASES。

现在可并行准备表情预览、屏幕采购、社团内容/角色草图和 echo 接口调查；实际实现优先交付 P1。未指定负责人，不表示已派发给其他 agent。

## 早期技术里程碑（保留原编号供交接）

- M0：电脑预览表情，确定视觉与屏幕布局。
- M1：真实 S3 屏幕显示脸和眨眼，脱离网络可运行。
- M2：真实屏幕经 Wi-Fi 接受手动演示状态，断线可恢复。
- M3：真实 echo agent 任务驱动屏幕，验证工作、等待、完成和失败。
- M4：装壳并做两小时展示测试，记录重启、断网和重连结果。

M2 是无线演示；M3 才是实际 echo 接入。M3 有主机兼容性风险，应在采购和制作复杂外壳前尽早验证。M0/M1 对应 P1，M2/M3 对应 P3，M4 是早期样机测试；这些 M 编号不包含完整版全部功能。
