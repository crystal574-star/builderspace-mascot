# 第一阶段：屏幕表情预览

电脑上看玩偶屏幕（320×240）会显示什么。2026-11-19 起，表情改用 EchoAgent 刘海 Bot 的：脸、样式、身形、配色和动作数值照 `EdwinjJ1/voice-agent`（提交 `5f4735aa`）的源码移植，画法改成 Canvas。

纯 HTML/CSS/Canvas，无依赖、不联网、不连接 echo-agent，没有远程字体或图片。

## 运行

从仓库根目录运行：

```sh
python3 -m http.server 8877 --bind 127.0.0.1 --directory preview
```

打开 http://127.0.0.1:8877 。按 Ctrl+C 停止；端口被占用时换一个端口。也可以直接双击 `index.html`。`index.html` 引用样式和脚本时带了 `?v=` 版本号，改了这三个文件后把版本号也改一下，浏览器才不会继续用旧缓存。

## 页面上有什么

- **屏幕**：左边的大屏是 320×240 放大后的样子；下面有一块按毫米显示的“实际大小”（约 40.8×30.6 mm，随显示器会有出入）。
- **状态**：协议七态 idle、listening、working、waiting、done、failed、offline，加原版多出来的“打瞌睡”。按 1–8 切换。
- **样式**：潮玩、贴纸、软糖、屏幕脸、像素。
- **平时的脸**：待机时用的那张，原版的八张里选。
- **配色**：原版的八套三段色。
- **身形**：圆、方糖、豆子、团子。
- **画面**：整只 Bot，或者脸铺满屏幕（整块屏当身体，只画脸）。
- **等你确认时**：招手或头顶感叹号。**做完了的特效**：撒彩屑、冒星星、对勾。
- **动作**：眨眼、左右张望、呼吸、看鼠标可以逐项关掉。点一下屏幕，它会缩一下再弹回。
- **自动演示**每 4 秒换一个状态；**暂停**冻结所有动作；空格眨一下眼；**导出**下载当前选择的参数 JSON。

系统开了“减少动态效果”时，眨眼、张望、呼吸、看鼠标默认关闭，可以手动打开。

## 哪些是原版，哪些不是

照原版的：11 张脸的路径和零件、按状态换脸的规则（干活认真、等你“哦”、做完大笑、睡着困）、五种样式的画法和系数、四种身形、八套配色、眨眼间隔、呼吸、张望、看光标、压扁回弹、干活点头、招手、感叹号、z、三种完成特效的数量和节拍。

不是原版的，等用户确认：

- **listening、failed、offline 三态**：原版没有。预览用原版零件拼了提议（大眼加小横嘴；挤眼加小横嘴；横线眼加整体调暗），页面上带橙点。
- **脸铺满屏幕**：为玩偶屏幕加的构图。高光挪到了屏幕左上角，手、感叹号、z 缩小后放在右上。
- **做完了**：原版是从刘海里跳出来再跳回去，这里改成原地跳一下；特效的尺寸按 320×240 缩过。
- **整只 Bot 背后的那团颜色**：取自原版对话卡片的做法。

没有移植：回声自己的护目镜形象、群聊里轮流张嘴、换样式时翻方块和漫画字的特效、眼镜和腮红这两种没有现成脸的配饰（零件数据在，页面上没有入口）。

## 文件

- `face-model.js`：数据（脸、样式、身形、配色）、动作算法、每一帧的状态和 Canvas 画法。不碰 DOM，Node 里也能跑。
- `app.js`：页面上的选项、键盘、鼠标和时间调度。
- `styles.css` / `index.html`：页面。
- `test-model.cjs`：模型测试。

内部坐标沿用原版的 40×40 格。整只 Bot 时一格 4 像素，脸铺满时一格 8 像素。导出的 JSON 里带路径字串、三段色、样式系数和各状态用哪张脸，可以交给固件移植；它不是 GPIO 配置，也不是设备协议。

## 检查

```sh
node --check preview/face-model.js
node --check preview/app.js
node --test preview/test-model.cjs
```

## 本轮验证结果（2026-11-19）

- 语法检查通过，13 项模型测试全过。种子、平时的脸、眨眼间隔、身形规则对的是 voice-agent 自己测试里的值。
- 内置浏览器里看过各状态在五种样式下的画面、两种构图、招手和感叹号、三种完成特效、打瞌睡、离线；1280 和 375 两个宽度下布局正常、无横向滚动，控制台无报错。
- 没做的：没有和原版 App 的画面逐像素比对；全屏和“减少动态效果”没有专项验收；真实 ST7789 屏幕、S3 上的帧率和颜色没有测。发光、渐变和像素化在 S3 上能不能跑得动还不知道。
