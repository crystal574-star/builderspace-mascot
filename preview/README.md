# 第一阶段：屏幕表情预览

纯 HTML/CSS/Canvas，无依赖、无需 API Key、不联网、不连接 echo-agent。所有图形本地绘制，无远程字体或图片。外形只是预览容器，不是已确定的工业设计。

## 运行

可以直接双击 `index.html`。建议从仓库根目录运行：

```sh
python3 -m http.server 8877 --bind 127.0.0.1 --directory preview
```

打开 http://127.0.0.1:8877 。按 Ctrl+C 停止；端口占用时换一个端口。Python 3 标准库即可。

## 操作

- 七个状态按钮，或在页面按 1–7：idle/listening/working/waiting/done/failed/offline。
- 自然眨眼、自动移动眼神、鼠标跟随各自可开关。将鼠标移入屏幕，眼神会跟随；移出回到自动视线。
- 点击“眨一下眼”，或页面按空格。按钮获得焦点时空格保留浏览器默认按钮操作。
- “自动演示七态”每 5 秒切换，最后一个之后回到待机；手动选状态后重新计时。
- “暂停动画”冻结表情过渡、视线、眨眼和自动轮播；暂停时仍可选择静态表情。
- 全屏按钮仅放大屏幕，Esc 退出；需要浏览器支持并允许全屏。
- “导出表情参数”下载 JSON，可交给固件开发者；这不是 GPIO 配置或设备协议。

系统开启“减少动态效果”时，默认关闭自然动作，切换不做过渡；仍可主动点眨眼或开启动作。表情“完成”的眼睛本身就是弯曲笑眼；离线是细线眼，眼神移动主要在睁眼状态查看。

## 文件与移植边界

- `face-model.js`：独立数值模型、七态姿态参数、420ms 可打断过渡、200ms 眨眼、确定性的视线轨迹和 Canvas 绘制。
- `app.js`：电脑端控制与时间调度，无网络状态输入。
- `styles.css` / `index.html`：预览容器和响应式控制界面。
- `test-model.cjs`：模型边界与过渡测试。

内部画布固定 320×240，CSS 放大不改变逻辑坐标。真实 ST7789 屏幕和 SPI 性能尚未测试；电脑 RAF 帧率仅用于预览。后续可将 pose 参数与时间函数移植到 S3，Canvas 绘制需换成实际屏幕绘制函数。

## 检查

```sh
node --check preview/face-model.js
node --check preview/app.js
node --test preview/test-model.cjs
```

浏览器验收应覆盖：七态选择、自然眨眼、鼠标跟随、自动演示、暂停/恢复、键盘操作、小屏布局和参数导出。M0 预览完成不等于 P1 真机点屏完成。

## 本轮验证结果（2026-11-18）

Node 语法检查通过，7 项模型测试通过。内置浏览器验证七态唯一选中、说明更新、数字快捷键、轮播、暂停与暂停时静态选态、导出入口；视觉检查了待机、听取、完成笑眼与鼠标眼神跟随。移动断点、系统减少动态效果与全屏尚未做专项验收。真实屏幕未测试。
