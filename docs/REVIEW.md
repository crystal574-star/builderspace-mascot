## 硬件与预算变更

P1 候选为 ESP32-S3-DevKitC-1-N8R8（8MB Flash、8MB PSRAM）或经核对的同规格开发板，配一块 2 英寸 SPI 屏。买前核实板载模组后缀、排针、USB 接口和原理图；不同修订/兼容板不能套用同一引脚表。P4 不再默认第二次买主控，只评审当前 S3 能否承担选定音频组合。

S3 GPIO1–14 有电容触摸通道，但不是十四个必定空闲引脚，也不是十四个现成传感器。屏幕、音频、调试和触摸要统一分配引脚；先测电极、阈值和壳体材料。原生触摸失败才考虑外置模块。

来源：[S3 触摸官方资料](https://docs.espressif.com/projects/esp-idf/en/v5.3/esp32s3/api-reference/peripherals/touch_pad.html)、[DevKitC-1 官方型号表](https://docs.espressif.com/projects/esp-idf/en/v5.0.3/esp32s3/hw-reference/esp32s3/user-guide-devkitc-1.html)。

## 可行性失败后的路线

1. 首次握手失败先检查启动方式、环境变量是否进入新 App 进程、串口占用、版本与协议。
2. 同一问题有限排查后记录日志摘要和缺口，联系主机维护者确认，不通过假状态伪装接通。
3. P1/P2 和活动吉祥物继续有独立价值：保留本地表情、触摸、菜单/预录介绍；明确标注 echo 不可用。
4. 桌面任务协作单独标阻塞，由用户决定等待适配或更换明确支持的主机接口；不擅自替换成另一套 AI 服务或扩大预算。
