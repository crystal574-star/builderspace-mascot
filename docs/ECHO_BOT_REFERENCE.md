## 1. 表情零件：眼睛 × 嘴 × 配饰

| 类别 | 全部枚举 | 视觉含义 |
| --- | --- | --- |
| 眼睛 | `dot`、`big`、`arc`、`line`、`squint`、`ring`、`none` | 点眼、大眼、弯眼、横线眼、挤眼、圈眼、不显示眼睛 |
| 嘴 | `smile`、`tiny`、`w`、`open`、`o`、`smirk`、`none` | 微笑、小横嘴、猫嘴、张嘴笑、圆嘴、歪嘴、不显示嘴 |
| 配饰 | `none`、`shades`、`glasses`、`brows`、`blush` | 无、墨镜、眼镜、眉毛、腮红 |

组合键为 `眼睛.嘴.配饰`。墨镜会遮掉眼睛，不能把所有组合都理解为视觉上不同的脸。脸部几何坐标系为 40×40、y 向下，移植时按屏幕缩放。

## 3. 原项目状态规则

| 原状态 | 默认脸与行为 |
| --- | --- |
| `rest` | 按 ID 从待机池选出的那张脸 |
| `working` | keen，加工作点头；群聊可能改用轮流说话 |
| `waiting` | wow，加招手或感叹号 |
| `done` | glad，加完成跳出和所选特效 |
| `asleep` | sleepy，加下沉、歪头和 z |

若用户自选过脸：rest/working 通常保留自选；waiting 换圈眼圆嘴，done 换弯眼张嘴，asleep 换横线眼小嘴；戴墨镜时保留墨镜眼部。默认 Echo 标志是另一种身份外观：白圆与黑色三根声波条，不等同于表情库中的普通脸。

**玩偶的七态尚未全部映射**：idle 可对应 rest，working/waiting/done 有直接参考；listening 和 failed 在这套 Mood 中没有独立项，需要讨论；offline 是连接事实，asleep 是角色休息，不能未经确认当作同义状态。原项目脸/气泡的点击审批行为不移植到玩偶摸头，既有安全边界不变。

## 5. 全部四种屏幕内身形

`circle` 圆、`squircle` 方糖、`bean` 豆子、`dome` 团子。原项目按 ID 的种子决定身形；Echo 标志与经典样式固定为圆。这里是屏幕内的小人轮廓，不是实体外壳的 CAD、尺寸或最终材质。

## 7. 基础动态全集

| 动态 | 触发与表现 | 参考时间/规则 |
| --- | --- | --- |
| 自然眨眼 | 按 ID 错开间隔；只缩眼睛层 | 间隔约 3.2–6 秒；新版闭眼段约 0.16 秒；done/asleep/标志脸有例外 |
| 换脸眨眼 | 合眼时换脸再睁眼 | 新旧绘制实现的时长不同，移植时选定版本 |
| 呼吸 | 底部为轴横竖轻微伸缩 | 周期 2.6–3.4 秒，按 ID 错开相位；睡着更慢、幅度更大 |
| 压扁回弹 | 状态变化时弹一下 | 弹簧参考 k=520、d=13，幅度受样式控制 |
| 看光标 | 脸朝光标挪，身体轻转 | 距离约 450 点内、光标 3 秒内动过；视线弹簧参考 k=70、d=12 |
| 闲时张望 | 看左、看右、回正，小幅上下看 | 每次停留约 1.6–4.2 秒；按 ID 稳定生成 |
| 打瞌睡 | 横线眼、下沉、歪头、飘 z | 所有 Bot 待机超过 3 分钟；有任务/等待/完成/悬停时唤醒 |
| 工作点头 | 认真脸，身体压缩、脸下移 | 约每秒 1.35 次，半波平方节奏；不等于真实舵机动作 |
| 工作灯/声波 | visor 天线灯闪烁；Echo 标志三条跳动 | visor 灯约 0.9 秒周期 |
| 群聊转向 | 两个以上同群 Bot 看向彼此 | 小人转向与横向偏移，停用工作点头 |
| 轮流张嘴 | 群聊的 Bot 轮流说话 | 每个约 1.1 秒；嘴约每秒 5.7 次开合；这是视觉节奏，不是音素口型 |
| 等待招手 | 右上举手，身体轻晃 | 手约 sin(10t)，身体约 sin(3.2t) |
| 等待感叹号 | 琥珀块和感叹号上下弹 | 与招手是可选等待外观，非同时必开 |
| 按压反馈 | 按下时缩一下 | 由 pressed 状态驱动，不表示触摸硬件已接入 |

新版渲染位于 NotchBotView；旧 NotchFaceView 还有更简单的 0.52 秒往返点头与 0.6 秒两段跳跃。不要把旧版与新版参数混成一套“原版”。桌面 Core Animation/CSS 的低 CPU 特点不能直接当作 S3 的帧率保证。

## 8. 状态时刻与特效全集

### 等待与完成的角色动作

- 等待：Bot 探出，招手或举感叹号，配提示气泡；原设计约停 10 秒再缩回，保留等待提示。
- 完成：先跳出、落地压扁、放特效，再跳回；原设计整段约 3.7 秒。气泡显示完成与耗时。
- 多事件会排队；原项目的顶栏、刘海尺寸、气泡布局属于桌面容器设计，不直接套到 320×240 玩偶屏幕。

### 三种完成特效

| 键 | 内容 | 文档中的参考规模 |
| --- | --- | --- |
| `confetti` | 彩纸喷出，抛物线、旋转、末尾淡出 | 约 26 片，1.1–1.6 秒 |
| `stars` | 八角星向外飞、缩放旋转，配一圈波纹 | 约 12 颗，0.85–1.15 秒 |
| `check` | 圆形白对勾弹出并上飘，配波纹 | 约 1.5 秒 |

### 换样式特效

- 旧外观切为 5×5 小块，约 0.55 秒错开翻转到新外观。
- 翻转中白闪、局部横向错位、红/青 RGB 分离；多个 Bot 依次错开约 0.06 秒。
- 同时弹出样式对应的漫画字，约 0.9 秒缩放、上飘和淡出。
- 系统“减少动态效果”时原设计关闭动作/特效，直接换样式。

这些是原设计/源码的参考内容，不意味着玩偶一定全开；特别是彩屑、模糊、阴影和切块特效，要先确认视觉方向，再测小屏和 S3 性能。

## 9. 下一次设计沟通要确认的事

1. 先展示原版六种样式的对照，用户选定要沿用哪一种/哪几种；不自行重画成另一个风格。
2. 选脸、颜色、屏幕内身形，确认是否保留配饰与标志。
3. 在上述视觉上讨论七态映射，尤其 listening、failed，以及 offline 与 asleep 的区别。
4. 逐项选动态：眨眼/视线/呼吸优先；招手、z、完成与换样式特效按用户确认选择。
5. 用户确认方案后再改 preview；参考资源记录完整，不等于授权一次实现所有效果。
