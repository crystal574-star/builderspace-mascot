## P1 电脑预览交接（2026-11-18）

- 分支：`codex/screen-expression-preview`；文件：`preview/index.html`、`styles.css`、`face-model.js`、`app.js`、`test-model.cjs`、`README.md`。
- 功能：七态、自然眨眼、视线、鼠标跟随、420ms 可打断过渡、5秒轮播、暂停、1–7/空格、全屏入口与 JSON 参数导出。
- 运行：根目录 `python3 -m http.server 8877 --bind 127.0.0.1 --directory preview`，或双击 HTML。无依赖、无网络接口、无 echo 连接。
- 验证：Node 语法检查；7 项模型测试全部通过；内置浏览器七态均唯一选中并更新说明；实际看过待机、正在听和笑眼；轮播与暂停/静态切换、数字快捷键、导出入口验证通过；鼠标移入屏幕可改变眼神。
- 限制：移动端断点和系统减少动态效果仅有代码处理，尚未做专门浏览器仿真；全屏入口存在但尚未完整验收；没有真实 S3、触摸或 echo 联调证据。
- 下一步：用户确认表情方向；按已购买的屏幕与 S3 型号做点屏和参数移植。电脑 FPS 不当成硬件性能。
