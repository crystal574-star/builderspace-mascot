## P1 电脑预览交接（2026-11-19 改版）

- 分支：`codex/screen-expression-preview`；文件：`preview/index.html`、`styles.css`、`face-model.js`、`app.js`、`test-model.cjs`、`README.md`。
- 来源：`EdwinjJ1/voice-agent` 提交 `5f4735aa` 的 `BotFaceGeometry.swift`、`NotchStyle.swift`、`NotchBotView.swift`、`docs/notch-bots.md`。脸的路径、种子算法、样式系数、身形、三段色、弹簧和节拍照搬；画法从 Core Animation 改成 Canvas。
- 功能：协议七态加原版的打瞌睡；5 种样式；8 张平时的脸；8 套配色；4 种身形；两种画面（整只 Bot、脸铺满屏幕）；眨眼、张望、呼吸、看鼠标、按压回弹、干活点头、招手或感叹号、做完了跳一下加三种特效；自动演示、暂停、全屏、导出 JSON；旁边按毫米显示实际大小。
- 不是原版的部分：listening（大眼加小横嘴）、failed（挤眼加小横嘴）、offline（横线眼加调暗）是用原版零件拼的提议；“脸铺满屏幕”是为玩偶屏幕加的构图；做完了改成原地跳（原版是从刘海跳出来）；特效尺寸按 320×240 缩过；整只 Bot 背后的那团颜色取自原版对话卡片。回声自己的护目镜形象、群聊轮流张嘴、换样式翻方块特效没有移植。
- 运行：根目录 `python3 -m http.server 8877 --bind 127.0.0.1 --directory preview`，打开 http://127.0.0.1:8877 。无依赖、无网络接口、无 echo 连接。
- 验证：`node --check` 两个脚本通过；`node --test preview/test-model.cjs` 13 项全过，其中种子、平时的脸、眨眼间隔、身形规则对的是 voice-agent 自己测试里的值。内置浏览器里看过：各状态在潮玩、贴纸、软糖、屏幕脸、像素下的画面，两种构图，招手与感叹号，三种完成特效，打瞌睡的 z，离线调暗；1280 宽和 375 宽布局无横向滚动，控制台无报错。
- 未验证：没有和原版 App 的实际画面逐像素比对；Safari、Chrome 之外的浏览器；全屏；系统“减少动态效果”只有代码处理；真实 ST7789 屏幕、S3 性能和颜色。像素样式和发光、渐变在 S3 上的开销未评估。
- 许可：表情几何来自私有仓库 voice-agent。本仓库目前私有、仅用户一人；公开本仓库或对外分发前，需先取得 voice-agent 所有者同意。
- 下一步：用户在预览里选定样式、平时的脸、配色、身形和构图，确认或修改三项提议；然后导出参数作为视觉参数包 v1，交给固件移植。
